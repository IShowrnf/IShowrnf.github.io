Quick answers

How do I play?

Choose Play → Launch client. Wait for the game’s loading screen. Open Edit Profile to set your username and skin, then use Singleplayer or Multiplayer.

How do I open the in-game GUI?

Press Right Shift in the client. Press it again or use Escape to close the custom menu.

Can I join any Minecraft server?

Browser multiplayer requires a compatible Eaglercraft WebSocket server or bridge. The launcher does not translate Minecraft protocols.

Why are modern items not behaving like 26.2?

This build uses the 1.12.2 engine. Modern items are visual replacements; their new gameplay abilities are not implemented.

Where are my worlds and preferences saved?

They are stored by the browser. Opening from a different website address, browser, or local file may use different storage. Keep world backups before changing hosts.

How do I host this launcher?

Extract the full website ZIP and publish its contents to a static host that you have permission to use. Keep the client and extras directories beside index.html. Only publish the game file if you have the necessary distribution rights.

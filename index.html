quick answers

does "play online" really not download anything?

your browser pulls the client once and runs it — like any website. no installer, no java, nothing saved to disk without you asking. your world is in browser local storage, so play from the same browser and it's still there.

where does the download save my world?

inside the html file itself — the offline build writes saves into its own storage. copy the file anywhere and your world goes with it.

mouse and keyboard only?

yes — minecraft 1.12 needs pointer lock and real keys. desktop or laptop strongly advised.
